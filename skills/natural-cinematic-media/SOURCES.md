# Sources and design inspirations

This NHD skill is an original synthesis. It does not vendor or reproduce upstream skill text.

Public projects reviewed as design references:
- https://github.com/soul0710/cinematic — cinematography vocabulary and structured shot thinking.
- https://github.com/raphaelbgr/ai-video-prompting — video prompting patterns, including Veo/Flow-oriented structure.
- https://github.com/Mikefluff/skills — model-aware image/video prompting and image-to-video motion discipline.
- https://github.com/fal-ai-community/skills — concrete cinematography terminology rather than generic prestige adjectives.
- https://github.com/Nanoleava/directing-image-prompts — specification-first image prompting and prompt linting concept.
- https://github.com/u2n4/gemini-media-mcp — layered media prompt architecture for Gemini/Veo workflows.

Before copying any upstream code or text into NHD MCP, inspect that repository's current license and preserve required attribution. This package intentionally uses independent wording and a dependency-free local linter.
