# Word Practice Sources

Use these sources as starting points, then refresh with web search for newer exercises when the user requests new tests.

## Reliable Starting Points

- Microsoft Learn Word Expert (Microsoft 365 Apps): https://learn.microsoft.com/en-us/credentials/certifications/mos-word-expert-m365-apps/
  - Use the assessed domains as the professional benchmark: document settings, advanced editing/formatting, custom document elements, and advanced Word features.
- GoSkills Word Advanced: https://www.goskills.com/course/word-2019-advanced
  - Use as a topic map for TOC, mail merge, labels, envelopes, captions, footnotes, track changes, and styles. Check whether files require an account before relying on downloads.
- Microsoft Support mail merge with Excel: https://support.microsoft.com/en-us/topic/how-to-use-the-mail-merge-feature-in-word-to-create-and-to-print-form-letters-that-use-the-data-from-an-excel-worksheet-d8709e29-c106-2348-7e38-13eecc338679
  - Use for practical merge tests with Excel data sources.
- Ferguson Library Word Advanced exercises PDF: https://www.fergusonlibrary.org/sites/default/files/2021-05/Microsoft-Word_Exercises_rev2020-09-08.pdf
  - Use for advanced hands-on tasks around TOC, styles, PDF export, and document cleanup.
- Easy4Me Word Advanced: https://www.easy4me.info/adv-word/
  - Use when downloadable exercise files and solutions are useful; translate task wording if needed.
- GCFGlobal Word mail merge lesson: https://edu.gcfglobal.org/en/word2016/mail-merge/1/
  - Use for accessible mail merge practice files.
- WordOfficeGuide: https://wordofficeguide.online/
  - Use as a guide catalog for styles, templates, mail merge, collaboration, and long-document references; verify claims against Microsoft sources for high-stakes work.

## Hard Practice Pack Template

Create a 60-90 minute pack with:

1. Long document cleanup: fix heading hierarchy, styles, section breaks, TOC, captions, cross-references, and PDF bookmarks.
2. Template build: create reusable styles, content controls, headers/footers, document properties, and protected input areas.
3. Mail merge: connect an Excel source, handle blanks, preview edge records, merge to individual documents, and export to PDF.
4. Review scenario: add tracked changes and comments without destroying existing review history.

Score against accuracy, formatting consistency, automation use, accessibility, and final PDF quality.
