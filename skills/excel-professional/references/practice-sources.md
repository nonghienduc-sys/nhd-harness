# Excel Practice Sources

Use these sources as starting points, then refresh with web search for newer exercises when the user requests new tests.

## Reliable Starting Points

- Microsoft Learn Excel Expert MO-211: https://learn.microsoft.com/en-us/credentials/certifications/exams/mo-211/
  - Use the assessed domains as the professional benchmark: workbook settings, data management/formatting, advanced formulas/macros, and advanced charts/tables.
- Microsoft Support PivotTables and PivotCharts overview: https://support.microsoft.com/en-us/office/overview-of-pivottables-and-pivotcharts-527c8fa3-02c0-445a-a2db-7794676bce96
  - Use for PivotTable/PivotChart scenario design and refresh behavior checks.
- Spreadsheet Center Excel exercises: https://spreadsheetcenter.com/excel-exercises/
  - Use advanced tasks such as A/B test analysis, reconciliation, XLOOKUP multiple criteria, DCF, XIRR, text parsing, and cohort retention.
- Automate Excel practice worksheets: https://www.automateexcel.com/practice-worksheets
  - Use the free workbook and automatically graded formula exercises.
- Excel Practice Online: https://excel-practice-online.com/
  - Use for browser-based practice with formulas, XLOOKUP, and Power Query topics.
- PivotXL pivot table practice workbook: https://pivotxl.com/pivot-table-practice-examples/
  - Use for PivotTable drills with downloadable workbooks.
- GoSkills Power Query and PivotTables challenge: https://www.goskills.com/Excel/Resources/Excel-challenge-3
  - Use for advanced Power Query and PivotTable practice when the user wants a timed challenge.
- ExcelDemy PivotTable practice data: https://www.exceldemy.com/excel-data-for-pivot-table-practice/
  - Use for additional PivotTable practice data; verify download availability before promising a file.
- MyExcelOnline PivotTable examples: https://www.myexcelonline.com/blog/101-excel-pivot-tables/
  - Use as a broad set of PivotTable examples and downloadable practice workbooks.
- Practice Datasets Online: https://practicedatasets.online/
  - Use for realistic datasets before building formulas, pivots, Power Query transforms, and dashboards.
- Wise Owl Advanced Excel course outline: https://www.wiseowl.co.uk/excel/course/excel-advanced/
  - Use as a topic map for advanced IFs, lookups, Power Query, advanced PivotTables, charts, scenarios, and goal seek.

## Hard Practice Pack Template

Create a 90-120 minute pack with:

1. Data cleanup: import messy data, normalize types, remove duplicates, and produce validation checks.
2. Formula model: build structured-table formulas using `XLOOKUP`, `SUMIFS`, `LET`, dynamic arrays, date functions, and error handling.
3. Analysis: create PivotTables, calculated fields/measures where appropriate, slicers/timelines, and a concise dashboard.
4. Financial/data challenge: build amortization, DCF/XIRR, cohort, reconciliation, or sensitivity analysis.
5. Automation: add a small VBA macro or repeatable Power Query step if the task calls for it.

Score against correctness, maintainability, refreshability, formula clarity, dashboard readability, and error checks.
