# Slide Design

## Workflow

1. Inspect the current deck visually, preferably by exporting slides to images and reviewing a contact sheet plus individual problem slides.
2. Identify recurring layout rules before editing: margins, header height, footer/nav style, type scale, card radius, table style, chart style, image treatment, and section divider style.
3. Redesign shared patterns first so slides feel like one deck, then tune individual slides with obvious imbalance, cramped text, or weak visual hierarchy.
4. Regenerate the deck and re-export previews after meaningful edits. Do not finish without checking rendered slides.

## Layout Rules

- Use a clear grid. Keep left/right margins consistent and align related objects to shared x/y coordinates.
- Balance each slide by visual weight, not only object count. Avoid one dense side and one empty side unless the design intentionally creates contrast.
- Keep repeated rows or cards equal in size. For five-card rows, use equal card widths, equal gaps, and a centered group.
- Avoid large unused lower areas. Move content downward or expand supporting blocks when the top half is overloaded.
- Keep section title slides simple and image-led if images are available; content slides should stay work-focused and readable.
- Do not put cards inside cards. Use cards for repeated items, tables, and compact framed content only.

## Typography

- Use a small type scale: title 20-28 pt, section label 14-18 pt, body 11-15 pt, source/footer 8-9 pt.
- Use bold only for headings, labels, and key numbers.
- Keep all text inside boxes with comfortable padding. If text wraps awkwardly, resize the box or reduce the number of words.
- Avoid decorative letter spacing and viewport-style scaling. Prioritize legibility at projection distance.

## Tables And Charts

- Place detail tables near the slide that discusses them, not at the end unless the user asks for an appendix.
- Table headers should be dark brand color with white text; body rows should alternate lightly.
- Keep table font large enough to read on a 1280x720 preview.
- Charts should have short titles, direct labels when possible, readable axes, and consistent colors.
- If a chart is too small or dark, rebuild it or enlarge it rather than leaving it as a screenshot.

## Visual Style

- Use the deck's brand colors as anchors, but avoid a one-note palette. Add neutral backgrounds and one accent color for emphasis.
- Prefer real, relevant images for cover, section dividers, and closing slides.
- Use restrained shadows and borders. Keep radius modest and consistent.
- Remove leftover template artifacts, irrelevant logos, old brand text, and mismatched colors.

## Final Check

- Export all slides to images.
- Review the contact sheet for rhythm and section flow.
- Review individual edited slides at full size for clipping, overlaps, low contrast, tiny tables, and misaligned objects.
- Verify the final deck has the intended slide order and no stale appendix or template text.
