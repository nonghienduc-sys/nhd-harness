## v0.7 features

### Persistent Terminal Sessions

v0.7 adds a bounded persistent terminal context without introducing an unrestricted background shell.

New tools:

- `terminal_session`
- `terminal_session_preview`
- `terminal_session_execute`

Persistent state is process-scoped and survives stateless MCP request boundaries while the workstation bridge process remains running.

The session stores only bounded execution context:

- approved working directory,
- approved environment variable deltas,
- sequence number,
- active-step identity,
- bounded verified step history,
- TTL / state.

### Security invariants

Persistent sessions do **not** bypass the existing Terminal safety model.

Every executable step still requires:

1. `TerminalService.preview`,
2. risk classification,
3. exact command hash,
4. one-time confirmation token,
5. exact critical confirmation phrase for critical commands,
6. bounded timeout,
7. result verification / session state update.

A failed or ambiguous execution is never automatically retried.

### Environment binding

Approved session environment variables are bound into the preview hash and pending action.

Allowlisted persistent environment deltas:

- `NODE_ENV`
- `PYTHONUTF8`
- `PYTHONIOENCODING`

The values themselves are not echoed in the public session representation; only environment names are exposed.

Unapproved variables, including attempts to override `PATH`, are rejected.

### Working-directory semantics

Persistent cwd is explicit session state rather than inferred from a child PowerShell process.

- cwd must remain inside configured roots,
- production sessions require the directory to exist,
- `cd`, `Set-Location`, `Push-Location`, `Pop-Location`, and equivalent directory-changing shell commands are blocked inside session steps,
- callers use `terminal_session` with `action=set_cwd` to change cwd safely.

### Session lifecycle

Session states:

- `open`
- `busy`
- `failed`
- `closed`
- `expired`

Defaults in production:

- maximum active sessions: 4
- session TTL: 30 minutes
- bounded history: 50 steps

Emergency Stop closes/invalidate active terminal sessions.
