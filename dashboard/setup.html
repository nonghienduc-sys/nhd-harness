2. Thêm NHD vào ChatGPT

Trong ChatGPT Web: Plugins → + → Add custom MCP server. Chọn Server URL và nhập URL đã kiểm tra, hoặc chọn Tunnel nếu sử dụng OpenAI Secure MCP Tunnel. Xác thực và xác nhận quyền truy cập trong chính ChatGPT.

Chỉ báo “hoàn thành” sau khi bạn đã kết nối và gọi thử một công cụ đọc trong ChatGPT. NHD không tự cấp quyền hoặc tự tạo plugin thay người dùng.
